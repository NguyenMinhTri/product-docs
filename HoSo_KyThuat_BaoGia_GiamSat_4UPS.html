Giải Thích Kỹ Thuật — Kiến Trúc Mạng

Giải thích chi tiết cách kết nối 4 UPS với 1 Gateway Navis MOD qua mạng Ethernet/Modbus TCP/IP.

❓

Vấn Đề: Gateway NM03 chỉ có 1 cổng Ethernet

Cần kết nối 4 UPS + cấp Internet cho Gateway → tối thiểu 6 cổng Ethernet

Gateway Navis MOD NM03 chỉ có 1 cổng Ethernet (RJ45). Trong khi đó, hệ thống cần:

  • 4 kết nối Modbus TCP — mỗi UPS cần 1 kết nối Ethernet để Gateway đọc dữ liệu qua Modbus TCP/IP
  • 1 kết nối Internet — Gateway cần Internet (Ethernet từ Router) để đẩy dữ liệu lên Cloud
  • Tổng cần: 6 cổng Ethernet — 4 UPS + 1 Gateway + 1 đường Internet từ Router
✅

Giải Pháp: Router 4G + Switch Ethernet 8 port

Dùng Router cấp Internet & Switch gom mạng Ethernet cho tất cả thiết bị

Sử dụng Switch Ethernet công nghiệp 8 port làm trung tâm kết nối mạng nội bộ, kết hợp Router 4G cấp Internet cho Gateway đẩy dữ liệu lên Cloud:

  • Switch 8 port — Gom tất cả thiết bị vào 1 mạng LAN: Port 1→UPS #1, Port 2→UPS #2, Port 3→UPS #3, Port 4→UPS #4, Port 5→Gateway NM03, Port 6→Router (Uplink Internet)
  • Router 4G — Lắp SIM Data, cấp Internet cho Switch → Gateway NM03 lấy Internet đẩy dữ liệu lên Cloud. Router cũng cấp DHCP cho toàn bộ mạng LAN
  • Cấu hình IP tĩnh — Mỗi UPS cần được đặt IP tĩnh (ví dụ: 192.168.1.101 ~ 104). Gateway NM03 cũng đặt IP tĩnh (192.168.1.100). Router: 192.168.1.1 (Gateway mặc định)

📌 Cách hoạt động

Gateway NM03 kết nối vào Switch → qua mạng LAN đọc thanh ghi Modbus TCP của 4 UPS (mỗi UPS là 1 Modbus Slave với IP riêng). Đồng thời, NM03 lấy Internet từ Router 4G (qua Switch) để đẩy dữ liệu lên Navis Cloud → hiển thị trên App & Web.

Switch Ethernet Công Nghiệp — 8 Port

Mạng 1 bộ — gom kết nối LAN cho 4 UPS + Gateway + Router

Switch Ethernet công nghiệp 8 port RJ45 10/100Mbps, Unmanaged (không cần cấu hình). Gom tất cả thiết bị trong hệ thống vào 1 mạng LAN để Gateway đọc Modbus TCP từ 4 UPS và lấy Internet từ Router.

  • Loại: Unmanaged Industrial Ethernet Switch
  • Cổng: 8 × RJ45 10/100Mbps
  • Nguồn: 12–48VDC hoặc 220VAC (tùy model)
  • Lắp đặt: DIN Rail hoặc vít
  • Phân bổ port: Port 1~4: UPS #1~4 | Port 5: Gateway NM03 | Port 6: Router 4G | Port 7~8: dự phòng
📡

Router 4G Công Nghiệp

Internet 1 bộ — cấp Internet cho Gateway đẩy dữ liệu lên Cloud

Router 4G LTE công nghiệp, lắp SIM Data Viettel/Mobifone, cấp Internet cho toàn bộ mạng LAN. Gateway NM03 lấy Internet từ Router qua Switch để đẩy dữ liệu lên Navis Cloud.

  • Kết nối: 4G LTE (Cat 4) — SIM Data di động
  • Cổng LAN: 1~4 × RJ45 (nối vào Switch)
  • Chức năng: NAT, DHCP Server, Firewall, VPN (tùy model)
  • Nguồn: 12VDC hoặc 9–36VDC (tùy model)
  • SIM Data: Gói Data 4G hàng tháng (ước tính ~2GB/tháng cho IoT)
🗄️

Tủ Điện & Vật Tư Phụ

Tủ điện 1 tủ — chứa Gateway, Switch, Router, nguồn 24V, CB, phụ kiện

Tủ điện chứa toàn bộ thiết bị hệ thống giám sát (Gateway, Switch, Router, nguồn, CB). Vật tư phụ bao gồm cáp mạng, đầu bấm RJ45, nguồn 24VDC, CB bảo vệ, rail DIN, máng cáp, v.v.

  • Tủ điện — Tủ sắt sơn tĩnh điện hoặc tủ nhựa IP65, kích thước ~W300×H400×D200mm
  • Nguồn 24VDC — Meanwell MDR-60-24, 24VDC/2.5A, DIN Rail — cấp nguồn cho Gateway NM03
  • CB bảo vệ — 1P 6A, bảo vệ ngắn mạch cho nguồn 24VDC
  • Cáp mạng Cat5e/Cat6 — 5 sợi (4 UPS + 1 Router), chiều dài tùy thực tế hiện trường. Đầu bấm RJ45
  • Anten 4G — Anten ngoài cho Router 4G (nếu tín hiệu yếu)
  • Rail DIN — Thanh ray lắp thiết bị trong tủ
  • Phụ kiện — Domino, đầu cos, dây rút, ống luồn, ốc vít lắp đặt
